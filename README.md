# ETN School 2026 — PEPS lectures and tutorial

Lecture and tutorial materials for the [European Tensor Network School 2026](https://www.newton.ac.uk/event/mmbw02/), covering projected entangled-pair states (PEPS) with an emphasis on infinite systems.

## Tutorial

[The two-dimensional classical Ising model](notebooks/Ising.ipynb)

- Construct a tensor-network representation of the partition function.
- Approximate the infinite environment using CTMRG.
- Compute the partition function per site and magnetization.
- Use automatic differentiation to obtain magnetization and specific heat.
